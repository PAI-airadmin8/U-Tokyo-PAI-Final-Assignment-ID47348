# AIロボ｜AIごみ回収ロボット（MuJoCo版）

AIが紙片・紙カップ・包装をPICK、私物をSKIPと判断し、ROS 2経由で回収動作につなげるシミュレーションです。

## 検証結果

- 3種類の初期配置で、ごみ9件を回収
- 私物3件をスキップ
- 単体テスト7件を通過
- 約85秒の実行動画を確認

## 実行方法

必要環境：ROS 2 Humble、MuJoCo 3.14.0、NumPy、ffmpeg、画面表示環境。

```bash
bash run_pai_c81_final3.sh
```

スクリプトはAIノードを起動し、3配置の実験、動画・rosbag2の記録、独立QA、単体テストを順に実行します。既定の出力先は `/tmp/pai_c81_v3_isolated_qa` です。変更する場合は `PAI_C81_OUT_ROOT` を指定してください。

## 検証範囲と制約

入力は実カメラ画像ではなく、MuJoCo上の仮想センサから得た色・寸法情報です。台車とアームは簡略モデルで、吸着も接触後に有効化する仮想拘束です。実機の走行・把持性能を示すものではありません。
