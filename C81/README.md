# C81｜AIごみ回収ロボット（MuJoCo版）

ここには、動作を検証したMuJoCo版のコード一式を置いています。
「C81」は開発時のコード名なので、動作するファイル名は変更していません。

AIが紙片・紙カップ・包装を回収対象と判断して拾い、
私物は拾わないPICK / SKIPの処理をROS 2でつなげました。
3配置でごみ9件を回収、私物3件をスキップし、単体試験は7件通過しました。

## 実行方法

ROS 2 Humble、MuJoCo 3.14.0、NumPy、ffmpegと
X画面が利用できる環境で実行します。

    bash run_pai_c81_final3.sh

このスクリプトはAIノードを起動して3配置を順に試し、
録画・rosbag2記録・独立検証を行います。

詳しいファイル構成は[実験メモ](実験メモ.md)にまとめました。
モデル定義ファイルだけを実行しても、回収動作は始まりません。

実カメラや実機を使った検証ではありません。
