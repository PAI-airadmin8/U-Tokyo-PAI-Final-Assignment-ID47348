# AIロボ｜ROS 2 + Gazebo / CRANE+ / MoveIt 2

Physical AI 応用編1の授業で使ったCRANE+をもとに、AIの分類結果でロボットアームの動作を変える実験です。

## 今までに確かめたこと

- Gazeboの仮想カメラから640×480のRGB画像を取得し、ROS 2経由でAI分類に渡す
- 物体をPICK、私物をSKIPと判定する
- MoveItで目標に接近し、GazeboのContactセンサで接触を確認する
- 接触した後、DetachableJointで仮想吸着する（指の摩擦だけで挟んでいるわけではない）
- 木塊を合計約59.75mm上げ、約126.40mm水平に動かした後、接続を外して机の上に落とす
- Gazeboの保存位置と状態を独立QAで確認：28項目PASS

## まだ足りないこと

これは**一つの配置で段階ごとに動かして確かめた実験**です。最初から最後までボタン一つで完全自動実行できる状態や、複数配置に対する安定性はまだ検証できていません。正式な1～3分の動画と、この実験だけで再現できるコード整理も未完成です。

したがって、この結果だけで学校の提出動画をMuJoCoからGazebo版に差し替えてはいけません。完成していない部分も含めて、今後の課題として記録しています。
