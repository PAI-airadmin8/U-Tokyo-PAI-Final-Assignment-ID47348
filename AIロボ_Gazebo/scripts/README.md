# 撮影・字幕処理の再現用スクリプト

ここには、2026年11月3日の正式録画で使用した画面準備と動画取得の処理を保存しています。

- `prepare_recording_scene.py`：Gazeboの独立ワールドを事前起動し、画面・カメラ位置を用意する。
- `record_onepass.py`：一回の自動実行をX11から録画し、同じ試行のQA JSONと動画情報を対応づける。
- `qa_repository.py`：元動画のSHA256、QAの成功判定、字幕版の長さ、PDF・ソースをまとめて点検する。
- `create_japanese_video.py`：C81とCRANE+の**元動画を変更せずに保持したまま**、別ファイルに日本語の字幕表示版を出力する。

**注意：** 前の2本はAA8-N-0061のX11 `:97`、Docker環境、Gazeboサービス、画面サイズを前提とした**正式試行時の記録コード**です。既存GUIプロセスを終了する処理を含むため、一般の環境で無確認に実行しないでください。新しい試行の通常実行は上位ディレクトリの `run.sh` を使ってください。

動画の原本は `video/AIrobo_V3_Official_FINAL_Continuous_20261103.mp4` です。日本語字幕版は動画の上に文字を重ねて再エンコードしますが、フレーム削除・途中結合・再生速度変更は行いません。
