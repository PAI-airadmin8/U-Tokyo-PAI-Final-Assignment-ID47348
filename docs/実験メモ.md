# 実験メモ

## フォルダの見方

このリポジトリは最終課題で使用したコードをまとめたものです。「C81」は開発中のコード名なので、ソースファイルの名前は変更していません。

| ファイル | 役割 |
|---|---|
| C81/pai_c81_mujoco.py | MuJoCoのモデルと3種類の初期配置。**場面定義用**で、これだけでは回収動作は始まりません。 |
| C81/pai_c81_ai_node.py | 合成データから学習した4種類の分類器とROS 2の独立ノード |
| C81/pai_c81_robot_runtime.py | 移動、接触の確認、拾得、投下、結果の再確認 |
| C81/run_pai_c81_final3.sh | 3種類の配置を順に動かして録画・記録・検証 |
| C81/pai_c81_independent_qa.py | ログ、rosbag2、動画を使ったチェック |
| C81/test_pai_c81_protocol.py | 7件の単体テスト |

## 動かす前に

ROS 2 Humbleの環境で source /opt/ros/humble/setup.bash を実行し、MuJoCo 3.14.0とNumPyが使えることを確認します。動画生成にはffmpegと描画用の画面が必要です。授業用Dockerと同等の環境を想定しています。

run_pai_c81_final3.sh は ROS_DOMAIN_ID=77 を使います。別のROS実験と通信が混ざらないようにするためです。再実行するときは、前の出力ディレクトリと衝突しないようにしてください。

## 試したときに気になったこと

見た目の動きだけで成功を判断しないようにしました。ログで接触と回収箱への投下を確かめ、AIから応答がないときは回収動作を始めないようにしています。

初期配置を3パターンにしたのも、たまたま一度うまくいっただけにならないようにするためです。今回の範囲では回収9件、私物スキップ3件を確認できました。

ただし、まだ模擬ごみ4クラスしか扱っていません。実際の店内では人の動きや未知の物体、照明の違いもあるので、次に改善したい部分です。
