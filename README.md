ROS 2とシミュレーションを使い、AIの判断をロボットの動作につなげる課題に取り組みました。

## 構成

- [AIロボ_Gazebo](AIロボ_Gazebo/)：CRANE+を使った発展実験。1配置での分割動作と独立QA 28項目を確認済み。連続自動実行と正式動画は未完了です。
- [C81](C81/)：ROS 2とMuJoCoによるAIごみ回収ロボット。3配置でごみ9件を回収し、私物3件をスキップ。単体テスト7件と約85秒の動画を確認しています。

## 実験内容

AIが対象物を分類し、回収するものはPICK、私物はSKIPと判断します。その結果をROS 2経由でシミュレーション上のロボット動作につなげました。
