ごみと私物をAIで分類し、回収するかどうかを判断してから、ROS 2経由でロボットの動作につなぐシミュレーションに取り組みました。

- [AIロボ_Gazebo](AIロボ_Gazebo/)｜Gazebo・CRANE+版：1配置の分割動作を確認し、独立QA 28項目に合格。連続自動実行と正式動画は未完了です。
