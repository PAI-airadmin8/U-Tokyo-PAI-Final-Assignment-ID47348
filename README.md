# 【U-Tokyo】PAI最終課題_ID47348

## AIによる散乱ごみ回収ロボットのシミュレーション

Physical AI 応用編1 の最終課題用公開コードです。

**目的:** MuJoCoの仮想環境で紙片・カップ・包装を回収し、私物をAIで判別して回収しない動作を検証します。

### 実装

- **ROS 2 Humble:** ロボット観測データと独立したAIノードの分類結果を交換
- **AI:** 192件の合成学習例を用いた4クラスSoftmax分類器（paper / cup / wrapper / personal）
- **PICK / SKIP:** AI分類結果が回収するかどうかの動作判断に影響
- **MuJoCo 3.14.0:** 簡易移動台車、3軸直動工具、接触に基づく仮想吸着、運搬、回収箱への投下
- **独立検証:** 3種類の初期配置、ログ、rosbag2、単体試験7件

### 動作結果（限定した仮想条件）

| 検証 | 結果 |
|---|---|
| ごみ回収 | 3種類 × 3配置 = 9/9 |
| 私物の回収回避 | 3/3 |
| 独立単体テスト | 7/7 |
| ROS 2記録 | 計1,726メッセージ |
| 説明用動画 | 85.167秒 |

**実験の限界:** 実機ロボットや実カメラでの認識ではありません。AIの入力は仮想センサから得た色・寸法特徴量です。車輪/SLAM/6軸マニピュレータ/現場デジタルツインは実装していません。未知物体や実店舗での成功率を示すものでもありません。

### ソース構成

- C81/pai_c81_mujoco.py — 仮想シーンと3つの初期配置
- C81/pai_c81_ai_node.py — 独立した学習済みSoftmax分類ノード
- C81/pai_c81_robot_runtime.py — 動作、接触、移送、再確認
- C81/pai_c81_independent_qa.py — rosbag2、動画、実行ログの独立QA
- C81/test_pai_c81_protocol.py — 単体試験
- C81/run_pai_c81_final3.sh — 3配置の実行と録画

### 再現方法

授業のROS 2 Humble環境でMuJoCo 3.14.0とPython関連パッケージ、ffmpegおよび録画可能なXディスプレイを用意した上でC81に移動し次を実行します。

    bash run_pai_c81_final3.sh

この実行スクリプトは ROS_DOMAIN_ID=77 の独立領域でAIノードを起動し、3配置を実行して動画とrosbag2を保存し、独立QAと単体テストを実施します。実行先環境・ライブラリの依存関係は検証済みの授業コンテナと揃えてください。出力先の変更は PAI_C81_OUT_ROOT で指定できます。

### 独自に工夫した点

単純なPick and Placeに加え、AI分類による回収判断、私物の安全スキップ、物理接触を条件にした吸着、ROSメッセージの整合確認、異なる初期配置での独立検証を実装しました。
