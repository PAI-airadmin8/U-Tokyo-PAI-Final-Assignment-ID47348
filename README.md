# AIごみ回収ロボット｜ROS 2 × MuJoCo
Physical AI 応用編1 最終課題（ID47348）

## 何を作ったか

通路に落ちているものを、ロボットが何でも拾ってしまったら困ります。そこで、**ごみは回収し、私物はそのまま残す**シミュレーションを作りました。

紙片・カップ・包装・私物の4種類をAIで分類し、結果に応じてPICK（回収）またはSKIP（拾わない）を選びます。AIの判断を表示するだけでなく、ROS 2を通してMuJoCoのロボット動作につなげています。

「C81」は開発中に使っていたコード名です。作品名は「AIごみ回収ロボット」です。

## 仕組み

仮想センサ（色・寸法） → ROS 2 → AI分類 → PICK / SKIP → 移動・接触・回収 → 結果確認

- **ROS 2 Humble**：観測データとAIの回答を別ノード間でやり取りします。
- **AI**：合成データ192件で学習した4クラスのSoftmax分類器を使います。
- **MuJoCo 3.14.0**：簡易台車と3軸工具を動かし、対象物との接触を確認してから仮想吸着で持ち上げ、回収箱に落とします。

## 試して分かったこと

同じ配置で成功するだけでは少し不安だったので、初期配置を変えて3回試しました。

| 確認したこと | 結果 |
|---|---|
| ごみの回収 | 3配置 × 3個 = 9/9 |
| 私物を拾わない | 3/3 |
| 単体テスト | 7/7 |
| ROS 2通信記録 | 1,726メッセージ |
| 動画 | 約85秒 |

数字は**用意したシミュレーション条件での結果**です。実際の店舗で同じ成功率になるという意味ではありません。

## 自分なりに工夫したところ

参考例のようにアームを動かすだけではなく、まずAIに回収すべきものか判断させるようにしました。特に私物を間違って持っていかないことを大切にしています。

また、画面上では拾えたように見えても、実際に物体に触れたかどうかは分かりません。そこで接触の確認、持ち上げ、投下後の位置の確認まで行い、ROSのログと一緒に結果を残すようにしました。

## 動かし方

授業のROS 2 Humble開発環境、Python、MuJoCo 3.14.0、NumPy、ffmpeg、表示可能なX画面が必要です。rclpy と rosbag2 はROS 2側の環境を使用します。

    cd C81
    bash run_pai_c81_final3.sh

スクリプトは独立したROS 2 AIノードを立ち上げ、3種類の配置を実行した後、動画とrosbag2を保存してテストを行います。出力先は環境変数 PAI_C81_OUT_ROOT で変更できます。

ファイルの役割と実験時のメモは [実験メモ](docs/実験メモ.md) にまとめました。

## できていないこと

これは**実機ではなく、MuJoCo上の教育用シミュレーション**です。AIの入力は実カメラ映像ではなく、仮想センサの色・寸法情報です。実車輪での走行、SLAM、6軸アーム、現場と同期するデジタルツインは扱っていません。

今後は実際のカメラ画像を使った認識や、未知の物体での検証にも取り組みたいと考えています。
