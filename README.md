## 取り組んだこと

最初は、ごみを拾うだけでなく、私物は拾わない判断ができたら
面白いと思い、AIで分類した結果によって行動を変えるようにしました。
MuJoCo版では3配置で合計9件の回収、3件の私物スキップを確認しました。

その後、授業のCRANE+をGazeboでも動かしてみました。
対象へ接近し、接触したときに仮想吸着し、
持ち上げて運ぶ分割実験には成功しています。
ただし一度の起動で全部を自動実行するところはまだ調整中です。
